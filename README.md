# Ladder of Less Pain

### *70 years of developer tooling, or: how we stopped punching cards and started arguing with autocomplete*

A single-page educational visualization of software developer tooling from **1956 to 2026** — punch cards, Unix, Turbo Pascal, the web, Git, Docker, and finally AI agents.

**Live:** [fullergalway.github.io/ladder-of-less-pain](https://fullergalway.github.io/ladder-of-less-pain/)

---

## The bit that matters

> Tooling has always been changing. AI is a big change, but it builds on decades of continuous improvement that made software development easier.

Also known (more formally) as **The Abstraction Ladder**.  
Also known (more honestly) as **why your job still requires thinking**.

## Open locally

```bash
open index.html
# or
python3 -m http.server 8080
```

One file. No build. No bundler. No “just run these 14 setup scripts.”  
Ironically, that *is* progress.

## What you get

- Horizontal timeline across seven eras
- Animated ease/abstraction curve (jagged suffering → smooth intent)
- Tool chips with historical tooltips
- Click any era for a deeper side panel
- Light/dark mode
- A footer that will haunt your next stack rewrite:

  **Yesterday’s expert tool is today’s baseline. The craft remains.**
